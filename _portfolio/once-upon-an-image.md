Once Upon An Image is an AI pipeline that turns a photo into a short story. A vision agent analyzes the image to identify key objects and scenes, then hands off to a language agent that weaves those elements into a narrative.

The two-agent architecture keeps the vision and language concerns separate and makes it easy to swap out either model independently.

**Tech Stack:** TypeScript, Next.js, Python
